🏗 1. 專案架構

        │  MQTT JSON v6 (config / weather / stock / state / request)
        ▼

        ▼
M5StickS3 Firmware (src/main.cpp)
  BusModule · RssiModule · StockModule · WeatherModule · Carousel · KeyEngine

🕹 2. 全域按鍵矩陣 (Universal Input Map)

動作巴士 ETARSSI股票天氣選單
BtnA 單擊切換 P1–P4返回巴士切換股票警告 ↔ 九天變更設定
BtnA 長按 1.5s刷新 ETA重測 RSSI刷新報價刷新天氣儲存並退出
BtnA ×5全域切換模組 Bus→RSSI→Stock→Weather—
BtnB 單擊開啟選單返回巴士開啟選單開啟選單下一張卡
BtnB ×5全螢幕 WebApp 配對 QR Code

🌤 3. 天氣模組

強制豎屏 135×240。檢視 1：即時溫度、濕度、天文台警告色塊。檢視 2：九天預報條列（日期、溫度、PSR）。底部提示：A:九天 B:選單 / A:即時 B:選單。

🛡 5. 五大 Bug 防禦

  1. POSIX difftime 跨日 ETA 計算
  2. MQTT config/state/weather/stock 一律 retain: false
  3. ETL 站名後綴正則（≤5 中文字）
  4. 靜態 JsonDocument + 4096B MQTT buffer
  5. Carousel / 豎屏模組停用 IMU 四向旋轉

📱 6. Web CRM 配合要點

  • URL 自動配對 ?id=<DeviceID>
  • KMB/CTB 路線同步 + 站點 ID 選擇
  • WiFi / 亮度 / 語言 / RSSI 設定推送
  • HKO rhrread + fnd → /weather
  • Yahoo Finance → /stock
  • 訂閱 /request：裝置長按或開機請求自動回應
