MQTT Payload 參考

config（retained）：

{
  "v": 2,
  "busA": { "co": "KMB"|"CTB", "route", "stop", "svc", "bound", "name" },
  "busB": { "co": "KMB"|"CTB", "route", "stop", "svc", "bound", "name" },
  "settings": { "bright": 0-3, "timeout": 0-3, "english": bool,
    "display_mode": 0|1|2,
    "wifi": { "preset": 0-2, "ssid": "...", "password": "..." } }
}

display_mode: 0=Auto(IMU 4-way 0°/90°/180°/270°) · 1=Force Landscape · 2=Force Portrait

cmd（非 retained）：

{ "action": "refresh_eta"|"reboot"|"power_off", "seq": 123 }

status（M5 確認）：含 battery、wifi_info、busA/busB、settings
