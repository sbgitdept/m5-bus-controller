設定經 m5bus/<ID>/config（retained JSON）· 遠端指令經 /cmd（非 retained）

MQTT Payload 參考

config（retained）：

{
  "v": 2,
  "active_profile": 0,
  "profiles": [{ "name", "busA": {...}, "busB": {...} }, ...],
  "busA": { "co": "KMB"|"CTB", "route", "stop", "svc", "bound", "name" },
  "busB": { "co": "KMB"|"CTB", "route", "stop", "svc", "bound", "name" },
  "settings": { "bright": 0-3, "timeout": 0-3, "english": bool,
    "display_mode": 0|1|2,
    "wifi": { "preset": 0-2, "ssid": "...", "password": "..." },
    "radar": { "ssid": "...", "mac": "AA:BB:CC:DD:EE:FF" },
    "app_mode": "bus"|"rssi_monitor" }
}

display_mode: 0=Auto · 1=Force Landscape · 2=Force Portrait · app_mode 切換 Bus ETA / RSSI Monitor

cmd（非 retained）：

{ "action": "refresh_eta"|"reboot"|"power_off"|"rssi_monitor"|"bus_eta"|"scan_wifi"|"set_profile", "profile_id": 0, "seq": 123 }

wifi_scan（M5 發布）：{"networks":[{"ssid","bssid","rssi","ch"},...]} → m5bus/<ID>/wifi_scan

status（M5 確認）：含 battery、screen/settings.app_mode、radar_rssi/radar_pct（RSSI Monitor 模式時）

4-Profile 管理

M5：P1

儲存 4 組 Bus ETA 設定。M5 藍掣單擊循環切換 Profile；五連點進入 RSSI Monitor。

寫入 profiles[] + active_profile 至 MQTT config（retained）。

RSSI Monitor

設定 M5「RSSI Monitor」要追蹤的 WiFi SSID 或 BSSID（MAC）。裝置會強制直向 135×240 顯示，高靈敏度 RSSI 進度條（-30～-90 dBm）。 亦可遠端切換 Bus ETA ↔ RSSI Monitor 模式。

M5 RSSI：等待資料…

選「自動」時，M5 會 scan 目前所連 WiFi 的 SSID；亦可指定其他網絡名稱。

若填 MAC，將優先以 BSSID 比對。格式 AA:BB:CC:DD:EE:FF

經 MQTT config 傳送 settings.radar + settings.app_mode（retained）。
